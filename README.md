- 11/21（六）中午及下午分批抵達高鐵左營站。中午外帶老江南台總店的蛋餅和紅茶牛奶回住家看 MAMA，紅毯 11:30、典禮 14:00。約 15:30 到後驛附近的程式咖啡。
- 17:00 在後驛站 1 號出口地面集合，前往世運半月池應援。BTS 19:00 開唱。
- 建議 20:30 從世運出發，目標是 21:30 鯨魚堤岸 5 號水舞末場。若來不及，可直接拍高流與 85 大樓應援。23:00 左右回住宿。
- 11/22（日）約 12:00 在汕頭泉成沙茶火鍋中山總店吃午餐，餐後解散。

高鐵班次及住宿定位請向地陪確認。
